# Changelog

## 0.2.0

- Add secure email OTP login with persistent, permission-restricted Timeful sessions.
- Add `auth status` and `auth logout`.
- Add combined `results` output with respondent names and availability.
- Allow authenticated responses with `respond --as-me`.
- Allow deliberate session bypass with `--anonymous`.
- Prevent anonymous creation of blind polls.

## 0.1.0

- Create anonymous Timeful events.
- Read public events and response payloads.
- Submit guest availability.
